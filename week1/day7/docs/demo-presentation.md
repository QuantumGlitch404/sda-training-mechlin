# Questions to Prepare For

## Why did you use feature branches?

Feature branches keep individual changes separate and make code review easier.

## Why use React Hooks?

Hooks allow functional components to manage state, side effects and reusable logic.

## Why use Context API?

Context allows shared application data to be accessed without passing props through many components.

## Why use WebSocket?

WebSocket allows the application to receive updates over a persistent connection without repeatedly reloading the page.

## How did you handle WebSocket failures?

The WebSocket service tracks connection state, handles disconnects and attempts reconnection.

## Why use caching?

Caching reduces unnecessary repeated requests and improves response time.

## Why use a local WebSocket server?

It provides a controlled environment for testing real-time functionality during development.
