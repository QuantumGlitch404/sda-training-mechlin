# Day 23: Generative AI & LLM

## Overview

Day 23 focuses on Generative AI and Large Language Models.

The project demonstrates OpenAI, Hugging Face, and Ollama integrations,
along with an API for text generation, summarization, code generation,
and chat functionality.

## Learning Objectives

- Understand Generative AI and LLMs.
- Integrate OpenAI models.
- Integrate Hugging Face models.
- Understand local model execution with Ollama.
- Build AI-powered API endpoints.
- Learn prompt engineering basics.
- Understand AI security and cost control.

## Features

- OpenAI text generation
- OpenAI summarization
- OpenAI code generation
- OpenAI chat completion
- OpenAI embeddings
- Hugging Face text generation
- Hugging Face summarization
- Hugging Face question answering
- Ollama local model integration
- AI content-generation API
- Web AI integration
- Health-check endpoint
- Model listing endpoint
- Automated tests
- Generative AI documentation
